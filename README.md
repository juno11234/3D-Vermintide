#  Vermintide_Motive_Project
 ## 프로젝트 개요 
본 프로젝트는 1인칭 슈팅 게임으로 **오브젝트 풀**을 이용한 대규모 적 웨이브와   
**상속**을 이용한 다양한 몬스터 바리에이션, **전략 패턴**을 이용한 무기교체 시스템을 구현하는 것을 목표로 진행하였습니다.


##  개발 환경

>  개발 인원: 1인  
개발 기간: 2025.04.15~2025.05.02  
형상 관리: Github Desktop    
게임 엔진: Unity 2022.3.62f1   
IDE: Rider 2024.3.6

## 핵심 구현 내용
###  1. **전략패턴을 이용한 무기 시스템**
  * 외적, 내적, 투영 같은 수학적 원리를 이용한 이동 로직을 구현
  * 벽에 법선 벡터와 업 벡터를 외적하여 벽을 따라 달림, 해당 벡터를 플레이어의 전방 벡터와 내적하여 달릴 방향 결정
  * 슬라이딩 구간에서는 바닥의 법선 벡터를 구하고 다운 벡터에 투영
###  2.   **인터페이스를 활용한 상호작용 시스템**
  *  다양한 트랙을 활용한 카메라 워킹, 애니메이션, 오브젝트제어 기능으로 정교하고 빠른 인게임 연출 구현
  *  시그널 트랙을 활용하여 원하는 타이밍에 이벤트로 함수 호출 가능 해당 트랙으로 카메라 흔들림, 조작 및 UI 활성화/비활성화 기능 구현
###  3. **오브젝트 풀을 활용한 대규모 웨이브**  
  *  최소한의 조작 난이도 대비 최대한의 시각적 연출 능력 표현에 특화된 QTE 시스템 구현
  *  InputSystem에 액션맵을 만들어 입력감지 함수를 구독 입력한 값과 QTE 정답을 비교하고 성공 여부에 따라 이벤트 발송

##  이슈 해결사항  
###  1.  **몬스터 데미지 중복 문**
  *  **문제:** 무거운 수학함수인 제곱근 남발
  *  **원인:** 업데이트에서 돌아가는 로직이기 때문에 CPU에 부담을 줌
  *  **해결:** 시야 각도를 확인하던 Angle 대신 내적 함수 Dot을 사용, 거리를 확인하던 Distance 대신 sqrMagnitude 사용
###  2.  **그래픽 병목 현상 해결** 
  *  **문제:** 투영으로 벽달리기 구현시 벽이 기울어져 있으면 플레이어의 이동방향이 대각선으로 바뀜
  *  **원인:** 벽이 기울면 벽에 법선 벡터의 Y좌표가 0이 아니게 되므로 플레이어의 이동방향에 영향을 줌
  *  **해결:** 외적은 업벡터가 있는이상 법선 벡터가 어떻든 항상 업벡터의 수직인 벡터가 나오기 때문에 외적을 이용해 구현
## 회고 
###  1.  **정답보다는 선택과 집중** 
 * 최적화를 위해 오브젝트 풀을 도입하면서 자료구조 Queue를 사용하여 중간 데이터 접근 기능을 포기하는 대신 입출력 속도라는 이점을 얻었습니다. 
또한 Instantiate를 게임 시작 부분으로 몰아주어 부하가 걸리는 타이밍을 제어 해주어 런타임 중 프레임 드랍을 방지하였습니다.
위에 겪은 상황처럼 코드 최적화는 단순한 성능 향상이 아니라 현재 시스템의 목표를 위해 무엇을 포기하고 무엇에 집중할 것 인가를 선택하는 과정임을 배웠습니다.
### 2. **개발 편의성을 위한 싱글톤 남발**
 * 프로젝트 초기 빠른 기능 구현과 데이터 접근의 편의성을 위해 주요 매니저 클래스들을 싱글톤으로 설계했습니다.
하지만 싱글톤에 의존하는 클래스들이 늘어날수록 문제 원인을 추적하기 힘들어지고 강한 결합으로 인해 코드 수정이 예기치 않은 영향을 주어 유지보수성이 감소합니다.
차후 프로젝트에서는 싱글톤 사용을 최대한 지양하고 필요한 객체를 인터페이스 형태의 인자로 전달하는 의존성 주입 구조를 만들어 느슨한 결합 구조로 개선할 계획입니다
